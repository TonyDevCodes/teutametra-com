# Teuta Metra - Official Author Website

A fast, fully custom author website built entirely in vanilla HTML, CSS, and JavaScript - no frameworks, no bloat, no page-load lag. Designed and developed end-to-end for author Teuta Metra to showcase her books, connect with readers, and give her a professional online presence built specifically around her brand.

**Live site:** [teutametra.com](https://teutametra.com)

![Teuta Metra website](./Marve.png)

## Why vanilla JS

No React, no build step, no dependency bloat - a deliberate choice. An author site is content-first: it needs to load instantly, rank well on search, and stay maintainable for years without dependency-update headaches. Hand-rolled HTML/CSS/JS keeps the page weight minimal and the code fully transparent - every line does something, nothing is shipped "just in case" by a framework.

## Features

- **Book showcase** - cover art, descriptions, and purchase links for each title, laid out in a clean editorial grid
- **Author bio & background** - a dedicated section giving readers context on Teuta and her work
- **Newsletter / contact form integration** - direct channel for readers to connect, no third-party widget clutter
- **Legal pages** - privacy policy and terms of use, both custom-written and styled to match the site (not boilerplate dropped in)
- **SEO fundamentals done right** - `sitemap.xml` and `robots.txt` configured for proper indexing
- **Fully responsive** - tested across mobile, tablet, and desktop breakpoints; typography and imagery scale cleanly at every size

## Tech

HTML5, CSS3, vanilla JavaScript. No frameworks, no build tools, no package manager - deployed as static files for maximum speed and zero maintenance overhead.

## Built by

Designed and developed independently for the client, from initial concept through deployment - structure, styling, content integration, legal pages, and SEO setup all handled end-to-end.
