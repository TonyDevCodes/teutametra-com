# Teuta Metra — Official Author Website

Official website for author Teuta Metra, showcasing her books 
and providing a way for readers to connect.

## Features
- Book showcase with cover images and descriptions
- Author bio and background
- Newsletter/contact form integration
- Legal pages (privacy policy, terms of use)
- Fully responsive design

## Live site
[teutametra.com](https://teutametra.com)

## Tech
HTML, CSS, JavaScript (no frameworks)
